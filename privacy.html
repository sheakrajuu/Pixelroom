PRIVACY

Your image stays in this browser.

Pixelroomedit does not provide an application server that receives your images.

Local processing

Image pixels, masks, filters, adjustments, branding placement, metadata reading, and exports run locally in your browser. Saved sessions use IndexedDB in your current browser profile.

External libraries

The page loads ONNX Runtime Web and Tesseract.js from public CDNs. Auto-detect text needs an internet connection the first time the OCR library and English language data are loaded. The image itself is processed locally and is not uploaded by Pixelroomedit.

Metadata

JPEG EXIF information can be displayed in the Metadata section. When Remove metadata is enabled, EXIF data is omitted from JPEG exports. PNG and WebP exports are generated by the browser canvas.
